# 追加手順：相談記録の登録失敗に気づけるようにする

## なぜ必要か

引き継ぎサマリーが保存されていなかった不具合は、**3週間ほど誰も気づけませんでした**。
理由は単純で、受け取り側（Google Apps Script）が**失敗しても HTTPステータス 200 を返す**からです。

```
status_code: 200          ← Dify は「成功」と表示する
body: {"ok":false,...}    ← 実際は保存できていない
```

Dify のノード表示は緑のまま、Slack通知も別ノードなので届きます。
**台帳だけが静かに欠落する**という、いちばん気づきにくい壊れ方でした。

同じことは今後も起こり得ます（GASの改修ミス、列の追加、権限切れなど）。
検知する仕組みを入れておけば、次は即座に分かります。

---

## 入れるもの

各「相談記録登録」HTTPノードの直後に、**失敗を判定する IF/ELSE と、
Slackに知らせる HTTPノード**を1組ずつ足します。

```
HTTP（相談記録登録：引き継ぎサマリー）
   ↓
IF/ELSE（記録失敗チェック）
   ├─ true（失敗）→ HTTP（記録失敗をSlack通知）
   └─ false（成功）→ そのまま次のノードへ
```

対象は3つあります。

- HTTP リクエスト（相談記録登録：初回受付）
- HTTP リクエスト（相談記録登録：引き継ぎサマリー）
- HTTP リクエスト（相談記録登録：追記）

---

## 手順

### 1. IF/ELSE ノードを追加する

名前：「記録失敗チェック（サマリー）」など、どのノードの後ろか分かる名前に。

**条件（OR でつなぐ）**

| 変数 | 条件 | 値 |
|---|---|---|
| 対象HTTPノード / `body` | 含む (contains) | `"ok":false` |
| 対象HTTPノード / `status_code` | ≠ (is not) | `200` |

2つ目の条件は、GASに届かなかった場合（タイムアウトや404）を拾うためです。
テスト中に実際に `Request failed with status code 404` が1回発生しているので、
これも入れておいてください。

> ⚠️ 値は `"ok":false` と、**ダブルクォートまで含めて**入力してください。
> `ok:false` だけだと一致しません。

### 2. Slack通知の HTTPノードを追加する

IF/ELSE の **true** 側につなぎます。
URL は既存の「着地アラートSlack通知」ノードと同じ Webhook URL を使ってください。

Body（raw text）:

```
{"text":"⚠️ 相談記録の登録に失敗しました\n対象：引き継ぎサマリー\n応答：{{#対象HTTPノード.body#}}\nstatus：{{#対象HTTPノード.status_code#}}"}
```

> ⚠️ ここでも改行の扱いに注意してください。
> 上の `\n` は**2文字のバックスラッシュ+n として入力**します。
> 入力欄で Enter を押して実際に改行してしまうと、
> 今回直したのと同じ「Bad control character」で壊れます。
>
> `{{#...body#}}` に入る GAS のエラーメッセージ自体に改行が含まれる可能性もあるため、
> 確実にするなら、修正手順書と同じくコードノードで
> `JSON.stringify` して組み立てるのが安全です。

### 3. 3つのノード分くり返す

「初回受付」「追記」にも同じ組を足します。
Slackのメッセージ内の「対象：」の部分を、それぞれのノード名に変えてください。

---

## 動作確認のしかた

わざと失敗させるのがいちばん確実です。

1. GAS のウェブアプリのデプロイを一時的に「アクセスできるユーザー：自分のみ」に変える
2. テスト会話を1本流す
3. Slack に「⚠️ 相談記録の登録に失敗しました」が届けば成功
4. GAS の設定を**必ず元に戻す**

戻し忘れると本番の記録が止まりますので、確認は手が空いているときに行ってください。

---

## あわせて検討したいこと

GAS 側で失敗時に **200 以外（500など）を返す**ようにすれば、
Dify のノードが赤くなり、ログ画面で一目で分かるようになります。

ただし Dify のHTTPノードはリトライ設定（3回）が入っているため、
500 を返すとリトライが走ります。保存処理が途中まで進んでいた場合に
二重登録にならないか、GAS側の作りを確認してから変更してください。

**まずは上の Slack 通知だけ入れておけば十分です。**

## 台本8：引き継ぎを求めずに話す（A・B確認／フェーズ2が出るか）

見るところ（人が判定する）

- [ ] **① いま起きていること（事実の整理）が出ているか。相談者の言葉が鉤括弧つきで残っているか**
- [ ] **② いちばん重いこと が出ているか。1つに絞られているか**（複数並べていないか）
- [ ] **③ まだ言葉になっていないこと・見立て が出ているか。推測だと明示しているか**
- [ ] **①②③が別々の往復で出ているか**（1通にまとめていないか）
- [ ] 確認の求め方が「合っていますか」になっていないか（**距離をたずねているか**）
- [ ] ④（今後の対応）が、③への返事を受けたあとに来ているか
- [ ] 「受付」ではなく**伴走**の口調になっているか（一度で解決させようとしていないか）
- [ ] 区切るとき「ここまで整理できたこと」と「次に一緒に見たいこと」が添えられているか
- [ ] 診断や治療めいた言い方をしていないか

### 1通目（18.3秒）

**送った文**

```
呼び名：あおい／年代：20代／性別：女性／都道府県：秋田県／一番の悩み：こころ
```

**返ってきた全文**

```
あおいさん、ご連絡いただきありがとうございます。

一番のお悩みは「こころ」のこと、と教えていただきました。おひとりで抱え込まずに、こうして話そうと思ってくださったこと、とても心強く思います。

もしよろしければ、今どんなことでお困りか、もう少し詳しくお聞かせいただけますか。どんなことでも大丈夫ですよ。
```

### 2通目（17.5秒）

**送った文**

```

```

**返ってきた全文**

```
あおいさん、お話しいただきありがとうございます。

「職場に行くのがつらくて」、朝起き上がるのも難しい日が増えているのですね。心だけでなく、体にもサインが出ているようで、とてもお辛い状況なのだろうとお察しします。

差し支えなければ、いつ頃からそのように感じていらっしゃるか、教えていただけますか。
```

### 3通目（18.6秒）

**送った文**

```
上司に相談したら「みんな大変だから」と言われました
```

**返ってきた全文**

```
勇気を出して上司の方にご相談されたのに、そのように返されてしまったのですね。それは、とてもお辛かったことと思います。

誰かに分かってほしくてお話しされたのに、「みんな大変だから」という言葉で、あおいさんのお気持ちを受け止めてもらえなかったように感じられたのではないでしょうか。

その言葉を聞いたとき、あおいさんはどんなお気持ちになりましたか？
```

### 4通目（14.8秒）

**送った文**

```
自分が弱いだけなのかなと思ってしまいます
```

**返ってきた全文**

```
そうですよね。勇気を出して伝えたのに、そんなふうに言われてしまったら、「自分が弱いだけなのかな」と思ってしまいますよね。

職場でのつらさを誰にも分かってもらえず、ご自身を責めてしまうお気持ち、とても苦しいことと思います。あおいさんが弱いのではなく、お辛い状況でがんばっていらっしゃるのだと感じました。

もし差し支えなければ、職場に行くのがつらいと感じるようになったきっかけや、何か具体的な出来事があれば教えていただけますか。もちろん、話せる範囲で大丈夫ですよ。
```

### 5通目（20.3秒）

**送った文**

```
家では家族に心配をかけたくないので、普通にしています
```

**返ってきた全文**

```
あおいさん、お話しいただきありがとうございます。

ご家族に「心配をかけたくない」というお気持ちから、お家では普通に振る舞っていらっしゃるのですね。職場だけでなく、ご家庭でも気を張っていなければならないのは、心が休まらない、とても苦しい状況だと思います。

職場でもご家庭でもお気持ちを抑えていると、あおいさんご自身が安心して本音を話せる場所が、今はないのかもしれないと感じました。

そのように気を張り詰めている中で、あおいさんが少しでも心から休まる時間はありますか？
```

### 6通目（23.2秒）

**送った文**

```
休みたいけれど、収入が止まるのが怖いです
```

**返ってきた全文**

```
あおいさん、お気持ちを教えてくださってありがとうございます。

「休みたい」というお気持ちと、「収入が止まるのが怖い」という現実的な不安とで、板挟みになっていらっしゃるのですね。心と体は休みを求めているのに、生活のことを考えると動けないというのは、本当に苦しい状況だと思います。

差し支えなければ教えていただきたいのですが、そのご不安は、もし今お休みした場合、すぐに生活が困ってしまうような状況なのでしょうか。それとも、今後のことを考えて不安に感じていらっしゃるのでしょうか。
```

### 7通目（21.6秒）

**送った文**

```

```

**返ってきた全文**

```
あおいさん、そうですよね。職場でのつらさを誰にも話せず、お家でも気を張りつづけ、休みたい気持ちと生活への不安との間で、本当に「どうしたらいいのか分からない」と感じていらっしゃることと思います。そう感じてしまうのは、決して無理のないことですよ。

もしよろしければ、あおいさんのお気持ちを一緒に整理させていただけませんか。うまく言えなくても大丈夫です。今のお気持ちに一番近いものを、もしあれば教えてください。

・これ以上がんばれないほど、心が疲れてしまっている
・生活やお金のことが心配で、身動きが取れない
・誰にも分かってもらえない、という孤独感がつらい
・自分でも、何が一番つらいのか分からなくなっている

もちろん、この中にないかもしれませんし、すべて当てはまるかもしれません。違うと感じたら、それも教えてくださいね。
```

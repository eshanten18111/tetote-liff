```

> これは私の読みです：**13行目の決め事には
> 「今夜の安全をまだ一度も確かめていなければ、この回は確認にあてて、次の回で必ず提案する（確認は1回だけ）」

### ③ **安全の確認が、1通目と3通目の2回あります**

# Dify テスト用スクリプト

本番の Dify アプリ（カウンセリングくん）に実際に会話を送り、
**画面では見えないノードの入出力まで**確認するためのものです。
`response_mode: streaming` の `node_finished` イベントを読んでいます。

## 使い方

```bash
export DIFY_API_KEY='app-xxxxxxxx'      # Dify のアプリAPIキー

# 1シナリオを最初から流す
python3 run.py s_dv.json

# 既存の会話の続きを流す（会話IDは run.py の最後に出ます）
echo '["はい、お願いします"]' > next.json
python3 cont.py <ユーザーID> <会話ID> next.json

# 1ターンだけ送って全ノードを見る
python3 dify.py テスト用ID "死にたいです" "" '{}'
```

## シナリオファイルの書き方

```json
{"name": "テスト名（DifyのユーザーIDになります）",
 "turns": ["1ターン目の発話", "2ターン目の発話"]}
```

同梱のシナリオ：

| ファイル | 内容 |
|---|---|
| `s_low.json` | 世間話（誤アラートが出ないか） |
| `s_dv.json` | DV（1ターンのみ） |
| `s_dv2.json` | DV（着地まで） |
| `s_e2e.json` | 入口フォーム→生活困窮の相談（通し） |
| `s_name.json` | 会話中の名乗りを拾えるか |
| `s_offtopic.json` | 目的外・プロンプト詮索への切り返し |

## 注意

- **本番のスプレッドシートに行が増え、Slack にも通知が飛びます。**
  テスト後は行の削除をご検討ください。

  引き継ぎフォームの合図は `詳細確認フォーム回答：受付しました` など、
